## Design and Implementation of LangChain Expression Language (LCEL) Expressions

### AIM:
To design and implement a LangChain Expression Language (LCEL) expression that utilizes at least two prompt parameters and three key components (prompt, model, and output parser), and to evaluate its functionality by analyzing relevant examples of its application in real-world scenarios.

### PROBLEM STATEMENT:
To design and implement a LangChain Expression Language (LCEL) pipeline that accepts at least two prompt parameters, integrates the three core components—Prompt Template, Language Model, and Output Parser—and generates structured, reliable outputs for user queries. The implementation should be evaluated using relevant real-world examples to demonstrate its functionality, flexibility, and effectiveness in AI-powered applications.

### DESIGN STEPS:

#### STEP 1:
Create a prompt template with at least two input parameters (e.g., {topic} and {tone}) to dynamically generate prompts based on user input.

#### STEP 2:
Initialize and connect a compatible LLM (e.g., OpenAI GPT model) that processes the prompt generated by the prompt template.

#### STEP 3:
Configure an output parser (e.g., StrOutputParser) to convert the model's response into a clean and structured format.

#### Step 4: Build the LCEL Pipeline

Combine the Prompt Template, Language Model, and Output Parser using the LangChain Expression Language (LCEL) pipeline operator (|) to form an executable chain.

#### Step 5: Execute and Test the Pipeline

Provide different values for the prompt parameters, execute the LCEL chain, and verify that the generated outputs are accurate, consistent, and properly formatted.

#### Step 6: Evaluate the Results

Analyze the outputs using real-world examples (such as content generation, customer support, or question answering) to assess the pipeline's functionality, flexibility, and effectiveness.

import os
import openai

from dotenv import load_dotenv, find_dotenv

from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import DocArrayInMemorySearch
from langchain.prompts import ChatPromptTemplate
from langchain.schema.runnable import RunnableMap
from langchain.chat_models import ChatOpenAI
from langchain.schema.output_parser import StrOutputParser

# -----------------------------
# Initialize Model
# -----------------------------
model = ChatOpenAI(temperature=0)
output_parser = StrOutputParser()

# -----------------------------
# Create Astronomy Vector Database
# -----------------------------
vectorstore = DocArrayInMemorySearch.from_texts(
    [
        "The Sun is the center of our Solar System and is a G-type main-sequence star.",

        "Mercury is the closest planet to the Sun and has no natural satellites.",

        "Venus is the hottest planet in the Solar System because of its thick carbon dioxide atmosphere.",

        "Earth is the only known planet that supports life and has one natural satellite called the Moon.",

        "Mars is known as the Red Planet because of iron oxide on its surface.",

        "Jupiter is the largest planet in the Solar System and has the Great Red Spot, a giant storm.",

        "Saturn is famous for its spectacular ring system made mostly of ice and rock particles.",

        "Uranus rotates on its side with an axial tilt of about 98 degrees.",

        "Neptune is the farthest known planet from the Sun and experiences the strongest winds in the Solar System.",

        "The Milky Way is the galaxy that contains our Solar System and has billions of stars."
    ],
    embedding=OpenAIEmbeddings()
)

retriever = vectorstore.as_retriever()

# -----------------------------
# Retrieval Examples
# -----------------------------
print("Question 1 Retrieval:")
print(retriever.get_relevant_documents("Which is the largest planet in the Solar System?"))

print("\nQuestion 2 Retrieval:")
print(retriever.get_relevant_documents("What is the Milky Way?"))

# -----------------------------
# Prompt Template
# -----------------------------
template = """
Answer the question based only on the following context.

Context:
{context}

Question:
{question}
"""

prompt = ChatPromptTemplate.from_template(template)

# -----------------------------
# RAG Chain
# -----------------------------
chain = (
    RunnableMap({
        "context": lambda x: retriever.get_relevant_documents(x["question"]),
        "question": lambda x: x["question"]
    })
    | prompt
    | model
    | output_parser
)

# -----------------------------
# Question 1
# -----------------------------
result1 = chain.invoke({
    "question": "Which is the largest planet in the Solar System?"
})

print("\nAnswer 1:")
print(result1)

# -----------------------------
# Question 2
# -----------------------------
result2 = chain.invoke({
    "question": "What is Mars known as?"
})

print("\nAnswer 2:")
print(result2)

# -----------------------------
# Question 3
# -----------------------------
result3 = chain.invoke({
    "question": "Why is Venus the hottest planet?"
})

print("\nAnswer 3:")
print(result3)

# -----------------------------
# Question 4
# -----------------------------
result4 = chain.invoke({
    "question": "What is the Milky Way?"
})

print("\nAnswer 4:")
print(result4)

# -----------------------------
# Show Retrieved Context
# -----------------------------
inputs = RunnableMap({
    "context": lambda x: retriever.get_relevant_documents(x["question"]),
    "question": lambda x: x["question"]
})

print("\nRetrieved Context:")
print(inputs.invoke({
    "question": "Tell me about Saturn."
}))
